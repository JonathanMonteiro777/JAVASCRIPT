# 📘 Curso de JavaScript – Curso em Vídeo

Este repositório reúne todo o conteúdo que estudei e pratiquei durante o **Curso Básico de JavaScript** do [Curso em Vídeo](https://www.cursoemvideo.com/), ministrado pelo professor Gustavo Guanabara.  
O curso foi fundamental para o meu desenvolvimento como programador, me dando uma base sólida na linguagem JavaScript e ampliando minha compreensão sobre lógica de programação, manipulação de DOM, eventos e muito mais.

## 🧠 Conteúdos Estudados

### 🔹 Fundamentos do JavaScript

- O que é JavaScript e como ele funciona nos navegadores
- História e evolução da linguagem
- Sintaxe básica, variáveis, tipos primitivos
- Operadores aritméticos, relacionais e lógicos

### 🔹 Controle de Fluxo

- Estruturas condicionais: `if`, `else`, `switch`
- Laços de repetição: `for`, `while`, `do while`
- Controle com `break` e `continue`

### 🔹 Funções

- Criação e chamada de funções
- Parâmetros, retorno de valores
- Funções anônimas e arrow functions

### 🔹 Arrays e Objetos

- Criação e manipulação de arrays
- Métodos úteis de arrays (`push`, `pop`, `length`, etc.)
- Introdução a objetos e manipulação de propriedades

### 🔹 DOM e Eventos

- Entendendo o DOM (Document Object Model)
- Seletores (`getElementById`, `querySelector`, etc.)
- Alteração de conteúdo, estilos e atributos
- Tratamento de eventos: cliques, teclado, carregamento

### 🔹 Prática com Projetos

- Verificador de idade
- Gerador de tabuada
- Verificador de número primo
- Outros exercícios práticos com lógica e interação
