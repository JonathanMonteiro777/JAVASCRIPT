Sintaxe do JavaScript

A sintaxe do JavaScript é a forma como os comandos e instruções são escritos.

JavaScript é uma linguagem de programação baseada em objetos e eventos.

Os comandos são escritos em texto simples e podem ser executados em um navegador web.

A sintaxe do JavaScript é semelhante à de outras linguagens de programação, como C e Java.

Os comandos são compostos por palavras-chave, operadores, variáveis e funções.

Os comandos podem ser escritos em uma única linha ou em várias linhas.

Os comandos são separados por ponto e vírgula (;).

Os comandos podem ser agrupados em blocos usando chaves ({ e }).

Os comandos podem ser escritos em qualquer ordem, mas é recomendável seguir uma estrutura lógica.

Os comandos podem ser comentados usando a sintaxe de comentários do JavaScript.

Comentários

Os comentários são usados para documentar o código e podem ser escritos em uma ou várias linhas.

Os comentários de uma linha começam com duas barras (//) e os comentários de várias linhas são delimitados por /* e */.

Os comentários são ignorados pelo interpretador JavaScript e não afetam a execução do código.

Exemplo de comentário de uma linha:

// Este é um comentário de uma linha

Exemplo de comentário de várias linhas:

/* Este é um comentário de várias linhas. 
                  Este comentário pode ocupar várias linhas */

Os comentários são úteis para explicar o código e facilitar a leitura e manutenção do mesmo.

Os comandos JavaScript podem ser escritos diretamente em um arquivo HTML ou em um arquivo separado com a extensão .js.

Para incluir um arquivo JavaScript em um arquivo HTML, use a tag <script>.

Exemplo de inclusão de um arquivo JavaScript:

<script src="script.js"></script>

Os comandos JavaScript podem ser executados quando a página é carregada ou em resposta a eventos, como cliques de mouse ou pressionamento de teclas.

Os eventos podem ser associados a elementos HTML usando atributos, como onclick, onmouseover e onkeydown.

Exemplo de evento onclick:

<button onclick="alert('Botão clicado!')">Clique aqui</button>

Quando o botão é clicado, a função alert() é chamada e exibe uma mensagem de alerta.

Os eventos também podem ser associados a elementos HTML usando o método addEventListener().

Exemplo de uso do método addEventListener():

<button id="meuBotao">Clique aqui</button>
document.getElementById("meuBotao").addEventListener("click", function() {alert("Botão clicado!");});

Comandos de Saída

Os comandos de saída do JavaScript são usados para exibir mensagens na tela do usuário.

  • alert(): Exibe uma caixa de alerta com uma mensagem.
  • confirm(): Exibe uma caixa de confirmação com uma mensagem e dois botões (OK e Cancelar).
  • prompt(): Exibe uma caixa de entrada onde o usuário pode digitar um valor.

Exemplo:

                    alert("Olá, mundo!"); // Exibe uma caixa de alerta com a mensagem "Olá, mundo!"
                    confirm("Você está gostando do curso?"); // Exibe uma caixa de  confirmação
                    prompt("Digite seu nome: "); // Exibe uma caixa de entrada para o usuário digitar seu nome

Exemplo de uso:

                      let nome = prompt("Digite seu nome: "); // Solicita o nome do usuário
                      alert("É um grande prazer te conhecer " + nome); // Exibe uma mensagem de boas-vindas com o nome do usuário
