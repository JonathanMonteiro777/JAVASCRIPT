Operadores em JavaScript (parte 1)

Operadores Aritméticos

Os operadores aritméticos são usados para realizar operações matemáticas básicas.

  • Soma (+): Adiciona dois números.
  • Subtração (-): Subtrai um número de outro.
  • Multiplicação (*): Multiplica dois números.
  • Divisão (/): Divide um número por outro.
  • Módulo (%): Retorna o resto da divisão entre dois números.
  • Exponenciação (**): Eleva um número a uma potência.

Exemplo:

            let a = 5 + 3; // 8
            let b = a % 5; // 3
            let c = a * b ** 2; // 45
            let d = 10 - a / 2; // 6
            let e = 6 * 2 / d; // 2
            let f = b % e + 4 / e; // 3

            ordem de precedência:

            1. Exponenciação (**)
            2. Módulo (%) e Multiplicação (*) e Divisão (/)
            3. Adição (+) e Subtração (-)

            auto-atribuições:
            let x = 10; // 10
            x += 5; // x = x + 5; // 15 
            x -= 3; // x = x - 3; // 12
            x *= 2; // x = x * 2; // 24
            x /= 4; // x = x / 4; // 6
            x %= 2; // x = x % 2; // 0
            x **= 3; // x = x ** 3; // 0

            Incremento e Decremento:
            let x = 0; // 0
            x++; // x = x + 1; // 1
            x--; // x = x - 1; // 0

Exemplo de uso (soma):

            let num1 = 10;
            let num2 = 5;
            let resultado = num1 + num2;

            console.log("Resultado da soma: " + resultado); // Resultado da soma: 15

Exemplo de uso (subtração):

            let num1 = 10;
            let num2 = 5;
            let resultado = num1 - num2;

            console.log("Resultado da subtração: " + resultado); // Resultado da subtração: 5

Exemplo de uso (multiplicação):

            let num1 = 10;
            let num2 = 5;
            let resultado = num1 * num2;

            console.log("Resultado da multiplicação: " + resultado); // Resultado da multiplicação: 50

Exemplo de uso (divisão):

            let num1 = 10;
            let num2 = 5;
            let resultado = num1 / num2;

            console.log("Resultado da divisão: " + resultado); // Resultado da divisão: 2

Exemplo de uso (módulo):

            let num1 = 10;
            let num2 = 3;
            let resultado = num1 % num2;

            console.log("Resto da divisão: " + resultado); // Resto da divisão: 1

Exemplo de uso (exponenciação):

            let base = 2;
            let expoente = 3;
            let resultado = base ** expoente;

            console.log("Resultado da exponenciação: " + resultado); // Resultado da exponenciação: 8

Exemplo de uso (auto-atribuição):

            let x = 10;
            x += 5; // x = x + 5; // 15
            console.log("Resultado da auto-atribuição: " + x); // Resultado da auto-atribuição: 15

Exemplo de uso (incremento e decremento):

            let x = 0;
            x++; // x = x + 1; // 1
            console.log("Resultado do incremento: " + x); // Resultado do incremento: 1

            x--; // x = x - 1; // 0
            console.log("Resultado do decremento: " + x); // Resultado do decremento: 0
