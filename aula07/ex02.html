Operadores em JavaScript (parte 2)

Operadores Relacionais

Os operadores relacionais são usados para comparar dois valores.

  • Igualdade (==): Verifica se dois valores são iguais.
  • Desigualdade (!=): Verifica se dois valores são diferentes.
  • Idêntico (===): Verifica se dois valores são iguais e do mesmo tipo.
  • Não idêntico (!==): Verifica se dois valores são diferentes ou de tipos diferentes.
  • Maior que (>): Verifica se um valor é maior que outro.
  • Menor que (<): Verifica se um valor é menor que outro.
  • Maior ou igual (>=): Verifica se um valor é maior ou igual a outro.
  • Menor ou igual (<=): Verifica se um valor é menor ou igual a outro.

Exemplo:

        let a = 5;
        let b = 10;
        let c = '5';

        console.log(a == c); // true   (igualdade)
        console.log(a === c); // false (idêntico)
        console.log(a != b); // true   (desigualdade)
        console.log(a !== c); // true  (não idêntico)
        console.log(a > b); // false   (maior que)
        console.log(a < b); // true    (menor que)
        console.log(a >= c); // true   (maior ou igual)
        console.log(a <= b); // true   (menor ou igual)

Exemplo de uso (maior ou igual):

        let idade = 18;
        let idadeMinima = 18;

        if (idade >= idadeMinima) {
            console.log("Você é maior de idade.");
        } else {
            console.log("Você é menor de idade.");
        }

Exemplo de uso (idêntico):

        let senha = prompt("Digite a senha:");
        let senhaCorreta = "1234";

        if (senha === senhaCorreta) {
            console.log("Senha correta.");
        } else {
            console.log("Senha incorreta.");
        }

Exemplo de uso (igualdade):

        let a = 5;
        let b = 10;

        if (a == b) {
            console.log("Os valores são iguais.");
        } else {
            console.log("Os valores são diferentes.");
        }

Exemplo de uso (não idêntico):

        let a = 5;
        let b = 10;

        if (a !== b) {
            console.log("Os valores não são idênticos.");
        } else {
            console.log("Os valores são idênticos.");
        }

Exemplo de uso (desigualdade):

        let a = 5;
        let b = 10;

        if (a != b) {
            console.log("Os valores são diferentes.");
        } else {
            console.log("Os valores são iguais.");
        }

Exemplo de uso (maior que):

        let a = 5;
        let b = 10;

        if (a > b) {
            console.log("a é maior que b.");
        } else {
            console.log("a não é maior que b.");
        }

Exemplo de uso (menor que):

        let a = 5;
        let b = 10;

        if (a < b) {
            console.log("a é menor que b.");
        } else {
            console.log("a não é menor que b.");
        }

Exemplo de uso (menor ou igual):

        let a = 5;
        let b = 10;

        if (a <= b) {
            console.log("a é menor ou igual a b.");
        } else {
            console.log("a não é maenorou igual a b.");
        }

Operadores Lógicos

Os operadores lógicos são usados para combinar expressões booleanas.

  • E (&&): Retorna true se ambas as expressões forem verdadeiras.
  • OU (||): Retorna true se pelo menos uma das expressões for verdadeira.
  • NEGAÇÃO (!): Inverte o valor lógico da expressão.

Exemplo:

        let a = true;
        let b = false;

        console.log(a && b); // false (E)
        console.log(a || b); // true  (OU)
        console.log(!a); // false (NEGAÇÃO)
        console.log(!b); // true  (NEGAÇÃO)
        console.log(a && !b); // true (E com negação)
        console.log(a || !b); // true (OU com negação)

Exemplo de uso (&&):

        let idade = 18;
        let temPermissao = true;

        if (idade >= 18 && temPermissao) {
            console.log("Você pode entrar.");
        } else {
            console.log("Você não pode entrar.");
        }

Exemplo de uso (||):

        let usuario = "admin";
        let senha = "1234";

        if (usuario === "admin" || senha === "1234") {
            console.log("Acesso permitido.");
        } else {
            console.log("Acesso negado.");
        }

Exemplo de uso (!):

        let usuarioLogado = false;

        if (!usuarioLogado) {
            console.log("Você não está logado.");
        } else {
            console.log("Você está logado.");
        }

Exemplo de uso (&& com negação):

        let idade = 18;
        let temPermissao = false;

        if (idade >= 18 && !temPermissao) {
            console.log("Você pode entrar.");
        } else {
            console.log("Você não pode entrar.");
        }

Operador Ternário

O operador ternário é uma forma concisa de escrever uma expressão condicional.

Ele tem a seguinte sintaxe:

        condição ? valorSeVerdadeiro : valorSeFalso;

Exemplo:

        let idade = 18;
        let resultado = (idade >= 18) ? "Maior de idade" : "Menor de idade";
        console.log(resultado); // "Maior de idade"

Ele é uma alternativa ao uso de if-else e é útil para atribuir valores com base em uma condição.

O operador ternário é chamado assim porque ele tem três partes: uma condição, um valor se a condição for verdadeira e um valor se a condição for falsa.
