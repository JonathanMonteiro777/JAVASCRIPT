Condições Multiplas

Aprendendo sobre condições multiplas

As condições múltiplas são uma forma de controlar o fluxo de execução do código com base em várias condições. Elas permitem que você execute diferentes blocos de código dependendo do valor de uma variável ou expressão.

Por exemplo, você pode usar uma estrutura de controle como o switch para verificar o valor de uma variável e executar diferentes blocos de código com base nesse valor.

Sintaxe da Estrutura Switch.

A sintaxe básica da estrutura switch é a seguinte:

switch (expressão) {
        case valor1:
             // Código a ser executado se a expressão for igual a valor1 
              break;
        case valor2:
             // Código a ser executado se a expressão for igual a valor2
             break;
             // ... mais casos conforme necessário
        default:
             // Código a ser executado se nenhum dos casos acima for atendido
             break;
             }

O break é usado para interromper a execução do restante dos casos no switch após encontrar uma correspondência.

O bloco de código correspondente ao primeiro caso que corresponder à expressão será executado. Se nenhum caso corresponder, o bloco de código no default será executado.

Exercícios

Agora é sua vez de praticar! Tente resolver os seguintes exercícios:

  1. Sistema de Navegação por Abas:
    Imagine que você está desenvolvendo uma interface de usuário com diferentes abas de conteúdo. Ao clicar em uma aba, o conteúdo correspondente deve ser exibido, enquanto o conteúdo das outras abas fica oculto. Cada aba pode ser identificada por um valor específico (por exemplo, "home", "produtos", "servicos", "contato"). O sistema precisa verificar qual aba foi clicada e, com base nessa informação, manipular a visibilidade dos diferentes blocos de conteúdo.
  2. Processamento de Comandos de Texto em um Jogo:
    Em um jogo de aventura baseado em texto, o jogador pode digitar comandos como "ir norte", "pegar item", "examinar objeto". O sistema precisa interpretar o primeiro verbo do comando para determinar qual ação realizar. Por exemplo, se o jogador digita algo que começa com "ir", o sistema precisa verificar a direção ("norte", "sul", "leste", "oeste") e atualizar a localização do jogador. Se começa com "pegar", precisa identificar o item a ser pego e adicioná-lo ao inventário. A lógica para cada verbo (ir, pegar, examinar, etc.) é diferente.
  3. Conversão de Códigos de Status HTTP em Mensagens Informativas:
    Ao interagir com uma API web, você frequentemente recebe códigos de status HTTP como resposta (por exemplo, 200, 404, 500). Para fornecer uma melhor experiência ao usuário, você quer exibir mensagens mais amigáveis e informativas com base nesses códigos. Por exemplo, se o código for 200, exibir "Sucesso: A operação foi concluída com êxito". Se for 404, exibir "Erro: Recurso não encontrado". Se for 500, exibir "Erro no Servidor: Algo deu errado no servidor. Tente novamente mais tarde". O sistema precisa receber o código de status e, dependendo do seu valor, exibir a mensagem correspondente.

Nesses três exemplos, a estrutura switch seria uma forma clara e organizada de lidar com as diferentes possibilidades (abas clicadas, comandos digitados, códigos de status recebidos) e executar o bloco de código apropriado para cada caso. Cada case no switch corresponderia a uma das opções, tornando o código mais legível do que uma longa sequência de if-else if-else.

Lembre-se de testar seu código e verificar se ele funciona corretamente.
