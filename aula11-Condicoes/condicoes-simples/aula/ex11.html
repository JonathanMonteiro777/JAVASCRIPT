Condições em JavaScript

Estruturas de controle no JavaScript

As estruturas de controle são fundamentais para a lógica de programação. Elas permitem que você tome decisões com base em condições específicas.

Neste exemplo, vamos explorar as estruturas de controle mais comuns: if, else if e else.

A estrutura if é usada para executar um bloco de código se uma condição for verdadeira. O else if permite verificar várias condições, e o else é executado se nenhuma das condições anteriores for verdadeira.

Vamos ver um exemplo prático de como usar essas estruturas de controle em JavaScript.

Exercícios

Resolva os exercícios abaixo para praticar o uso de condições em JavaScript.

  • Exercício 1: Crie um programa que verifique se o veículo utrapassou o limite de velocidade.
  • Exercício 2: Crie um programa que verifica se a pessoa mora no brasil, ou se ela é estrageira.
  • Exercício 3: Crie um programa que verifique se uma pessoa é maior de idade (18 anos).

Exercício 1

Sistema de Multas

O sistema de multas deve verificar se o veículo ultrapassou o limite de velocidade e calcular o valor da multa caso o veiculo tenha exedido a velocidade permitida.

O limite de velocidade é de 60 km/h e a multa é de R$ 5,00 para cada km/h acima do limite.

Exercício 2

Verificação de Nacionalidade

O sistema deve verificar se a pessoa mora no Brasil ou se ela é estrangeira.

Se a pessoa for brasileira, exiba uma mensagem informando que ela é brasileira. Caso contrário, exiba uma mensagem informando que ela é estrangeira.

A nacionalidade deve ser informada pelo usuário.

Exercício 3

Verificação de Maioridade

O sistema deve verificar se a pessoa é maior de idade (18 anos).

Se a pessoa for maior de idade, exiba uma mensagem informando que ela é maior de idade. Caso contrário, exiba uma mensagem informando que ela é menor de idade.

A idade deve ser informada pelo usuário.
